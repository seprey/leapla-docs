In Docs you write notes and documents, and make spreadsheets.

## Creating a doc

Create a new doc as a document or as a spreadsheet. A doc belongs to a project or stands on its own. These are the same projects as in [Tasks](/features/tasks).

## Spreadsheets

A spreadsheet works with formulas, like in Excel:

| Formula | What it does |
|---|---|
| `=SUM(A1:A5)` | Adds up the cells |
| `=AVERAGE(A1:A5)` | The average |
| `=MIN(A1:A5)`, `=MAX(A1:A5)` | The smallest or largest number |

## Apla and your docs

[Apla](/features/apla) knows the titles of your docs. Apla only reads the content of the doc you have open, and it can suggest adding something to it. Nothing changes until you approve it.

## Free and Plus

Docs is part of **Personal Plus**. Without Plus, Docs is under the **+** in the menu with the label Plus and the button **Upgrade**.
