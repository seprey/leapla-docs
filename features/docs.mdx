In Docs schrijf je notities en documenten, en maak je rekenbladen.

## Een doc maken

Maak een nieuw doc als document of als rekenblad. Een doc hoort bij een project of staat los. Het zijn dezelfde projecten als in [Taken](/features/tasks).

## Rekenbladen

Een rekenblad werkt met formules, zoals in Excel:

| Formule | Wat ze doet |
|---|---|
| `=SOM(A1:A5)` | Telt de cellen op |
| `=GEMIDDELDE(A1:A5)` | Het gemiddelde |
| `=MIN(A1:A5)`, `=MAX(A1:A5)` | Het kleinste of grootste getal |

## Apla en je docs

[Apla](/features/apla) kent de titels van je docs. De inhoud leest Apla alleen van het doc dat je open hebt, en het kan voorstellen om er iets aan toe te voegen. Er verandert niets tot jij het goedkeurt.

## Gratis en Plus

Docs zit in **Persoonlijk Plus**. Zonder Plus staat Docs bij de **+** in het menu met het label Plus en de knop **Upgraden**.
